This update improves LLM inference performance on mobile and edge devices with Qualcomm Adreno GPUs, enabling broader deployment of large language models on resource-constrained hardware. The broadcast support allows efficient handling of matrix multiplication with broadcasting semantics, while the view_offs fix ensures correct memory offsets for Q8_0 quantized matrices in multi-stream scenarios.

github · github-actions[bot] · Jul 20, 06:29

**Background**: llama.cpp is an open-source C++ implementation for running large language models (LLMs) locally on various hardware. OpenCL is a cross-platform API for parallel computing on GPUs, and Adreno is Qualcomm's integrated GPU found in many mobile SoCs. The MUL_MAT operation performs matrix multiplication, a core computation in neural networks. Q8_0 is a quantization format that reduces model size and speeds up inference by representing weights with 8-bit integers.
