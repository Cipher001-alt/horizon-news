## [DRAM Row Hammer Exploit Achieves Ring-0 Privilege Escalation](https://github.com/xoreaxeaxeax/skitter-creek-bath-salts) ⭐️ 8.0/10

Security researcher Christopher Domas (xoreaxeaxeax) has released a new technique, dubbed 'Spaghettifying DRAM', that exploits the DRAM row hammer vulnerability to achieve ring-0 privilege escalation. The proof-of-concept is available on GitHub, targeting AMD Jaguar architecture (AMD16h) and potentially other families. This research demonstrates a practical hardware-level attack that can bypass traditional software security mechanisms, potentially affecting gaming consoles and other systems. It highlights the growing complexity of DRAM and the expanding attack surface, raising concerns for platform security teams. The exploit works on AMD Jaguar (AMD16h) as per the README, with notes about Zen 3 having a different base address for memory controller registers. The technique involves manipulating DRAM row hammer to gain ring-0 access, which is the highest privilege level in most operating systems.

hackernews · matt_d · Aug 13, 14:17 · [Discussion](https://news.ycombinator.com/item?id=49286341)

**Background**: Row hammer is a security exploit that exploits an unintended side effect in DRAM where repeatedly accessing a row of memory cells can cause bit flips in adjacent rows. Ring-0 is the most privileged level in the protection ring model, typically reserved for the operating system kernel. Achieving ring-0 access allows an attacker to execute arbitrary code with full system control.
