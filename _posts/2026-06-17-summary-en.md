## [RFC 10008 Introduces HTTP QUERY Method](https://www.rfc-editor.org/info/rfc10008/) ⭐️ 8.0/10

RFC 10008 defines a new HTTP method called QUERY, which allows sending safe and idempotent requests with a request body, distinct from GET and POST. This new method addresses a long-standing gap in HTTP for idempotent queries with bodies, improving API design consistency and enabling better caching semantics for complex queries. The QUERY method is safe and idempotent, meaning multiple identical requests have the same effect as a single request, and it does not modify server state.

hackernews · schappim · Jun 17, 10:51 · [Discussion](https://news.ycombinator.com/item?id=48568502)

**Background**: HTTP traditionally uses GET for idempotent queries but GET does not support a request body, while POST supports a body but is not idempotent. Developers often resorted to sending bodies with GET or using POST for queries, leading to interoperability issues. The QUERY method standardizes a safe, idempotent way to send query payloads.

**Background**: Commercial real estate loans are typically based on the property's appraised value, which depends on rental income. If rents fall, the property value drops, potentially triggering loan defaults. 'Extend and pretend' refers to lenders and borrowers agreeing to delay recognizing losses by pretending vacancies are temporary.
