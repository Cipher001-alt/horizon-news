## [GrapheneOS Protections Against Data Extraction from Locked Devices](https://discuss.grapheneos.org/d/40700-grapheneos-protections-against-data-extraction-from-locked-devices) ⭐️ 8.0/10

A community discussion highlights GrapheneOS's auto-reboot feature that returns the device to Before First Unlock (BFU) mode after a period of inactivity, preventing data extraction from locked devices. This feature significantly enhances mobile security by ensuring that even if a device is seized while locked, encryption keys remain inaccessible, protecting user data against forensic extraction tools. The auto-reboot feature triggers after 18 hours of inactivity, forcing the device into BFU mode where file-based encryption keys are not loaded into memory, making data extraction impossible.

hackernews · Cider9986 · Jul 26, 05:57 · [Discussion](https://news.ycombinator.com/item?id=49055169)

**Background**: BFU (Before First Unlock) is a state where the device has been powered on but not yet unlocked with the passcode, meaning encryption keys are not available. In contrast, AFU (After First Unlock) mode has keys in memory, making data potentially extractable. GrapheneOS is a security-hardened Android-based OS that prioritizes privacy and protection against physical attacks.
