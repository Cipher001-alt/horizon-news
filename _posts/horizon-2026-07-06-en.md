## [Tencent releases Hy3 open-source MoE model with 21B active parameters](https://the-decoder.com/tencent-releases-hy3-open-source-model-that-allegedly-matches-models-up-to-five-times-its-active-size/) ⭐️ 8.0/10

Tencent has released Hy3, an open-source Mixture-of-Experts (MoE) language model with 295 billion total parameters but only 21 billion active per token, claiming it matches models two to five times its active size while reducing hallucination rates to 5.4%. This release demonstrates that efficient MoE architectures can achieve performance comparable to much larger dense models, potentially lowering the cost and barrier to deploying high-quality LLMs in production. Hy3 has 295B total parameters with 21B active, plus a 3.8B MTP layer; it is optimized for STEM reasoning and backend coding tasks, and its weights are publicly available on Hugging Face.

rss · The Decoder — AI新闻 · Jul 6, 18:03

**Background**: Mixture-of-Experts (MoE) is an architecture that divides a model into multiple 'expert' sub-networks and activates only a subset for each input, enabling larger total capacity with lower computational cost. In contrast, dense models activate all parameters for every input. Active parameters refer to the subset used during a single forward pass, while total parameters count all weights in the model.
