## [Nub: A Bun-like toolkit for Node.js via preload hooks](https://github.com/nubjs/nub) ⭐️ 8.0/10

Nub is a new open-source toolkit that enhances stock Node.js with a transpiler and polyfills using preload hooks, enabling features like TypeScript support and modern APIs without replacing the runtime. Nub offers a lightweight alternative to Bun by leveraging existing Node.js infrastructure, allowing developers to adopt modern features incrementally without migrating to a new runtime, which reduces risk and migration effort. Nub uses a --require preload hook to inject an oxc-powered transpiler (via Node-API add-on) and polyfills for APIs like Worker and Temporal, while keeping Node's native engine and stdlib intact.

hackernews · colinmcd · Jun 24, 14:14 · [Discussion](https://news.ycombinator.com/item?id=48660267)

**Background**: Bun is an all-in-one JavaScript runtime that includes a bundler, test runner, and package manager, but requires replacing Node.js entirely. Nub takes a different approach by adding similar capabilities to stock Node.js via preload hooks, which are scripts that run before the main application to modify the runtime environment.

## [llama.cpp b9784: Major Hexagon DSP MUL_MAT Rework](https://github.com/ggml-org/llama.cpp/releases/tag/b9784) ⭐️ 7.0/10

llama.cpp release b9784 introduces a major rework of the MUL_MAT and MUL_MAT_ID operations for Qualcomm Hexagon DSP, featuring a 32x32 tiled weight repack, kernel-params, and cached graphs to improve inference performance. This optimization significantly boosts LLM inference speed on Qualcomm devices, enabling more efficient edge deployment of large language models. The rework reduces memory overhead and improves parallelism, benefiting mobile and embedded AI applications. The rework includes tiled weight repack aligned with DMA, dynamic quantization format optimization for q8_0 and q8_1, and removal of support for Hexagon architectures older than v73. It also introduces a fallback non-tiled mode and unified HVX/HMX microkernels.

github · github-actions[bot] · Jun 24, 19:55

**Background**: llama.cpp is a popular open-source C/C++ implementation for running LLM inference on various hardware. The MUL_MAT (matrix multiply) operation is the dominant computational bottleneck in transformer models. Hexagon DSP is a digital signal processor integrated into Qualcomm Snapdragon SoCs, often used for offloading compute-intensive tasks to improve power efficiency.

## [Implementing Git Storage on S3 with Go](https://www.tigrisdata.com/blog/objgit/) ⭐️ 6.0/10

A blog post describes implementing a Git storage backend on S3 using Go, named ObjGit, which uses Tigris Data's S3-compatible object storage with a custom rename header. This project explores a niche but practical use case of storing Git repositories directly on object storage, which could simplify backup and sharing for large repos. It also highlights the challenges of adapting Git's POSIX assumptions to S3's eventual consistency model. The implementation uses go-git and relies on Tigris's X-Tigris-Rename header for atomic renames, which is not available on standard S3. The author notes performance issues with git operations over S3 due to latency and lack of atomic operations.

**Background**: Git is a distributed version control system that traditionally stores data in a local filesystem. Object storage like Amazon S3 offers scalable, durable cloud storage but lacks POSIX filesystem semantics, making direct Git storage challenging. Projects like git-annex and ZeroFS provide alternative approaches to managing large files or mounting S3 as a filesystem.
